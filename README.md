Project Name: 2025-2026 Teacher Preparation Program Placements

Purpose: Explore the placements, schools, and demographic information for the 2025-2026 academic year. Where were TPP teacher candidates placed? What schools and students do they gain experience with?

Final streamlit app (10/21/2026): https://cmse830-midterm-denzin.streamlit.app/

AI Disclosure: No AI was directly used in the creation or work of this project.

Files
- requirements.txt = start here, explains reproducibility
- midterm.py = streamlit code and user facing visualizations
- MidTermProjectKatieDenzin.ipynb = jupyter notebook for cleaning data and reproducing results.
- placements.xlxs = compiled deidentified placement data from internal documents
- addresses.xlxs = school building addresses and lats/longs, from NCES
- studentcounts2526.xlxs = student demographic and enrollment data, from mischooldata.com
- buildings.csv = cleaned data, output of Jupyter Notebook
- demographics_cleaned.csv = cleaned data, output of Jupyter Notebook

Instructions
- To reproduce results, follow the instructions in the .ipynb and use the placements, addresses, and studentcounts2526 excel worksheets.
- Can run streamlit locally by uncommenting the code chunks under the "Streamlit" section of the .ipynb.

Requirements:

To run the completed version of this project, you need:

midterm.py (and ability to run streamlit local/deploy an app)
buildings.csv
demographics.csv

To simulate this project and recreate it, you need:

MidtermProjectKatieDenzin.ipynb
placements.xlxs
studentcounts2526.slxs
addresses.xlxs
